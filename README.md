# OBOMOCARE CBO

<img src="./assets/header.svg" width="100%" alt="OBOMOCARE" />

Community-based organization website for grassroots programs in Kisii and Nyamira. Programs, stories, media, diaspora engagement.

## Features

- 20+ pages: programs, impact, stories, team, gallery
- Mobile-first responsive layout
- PWA with offline caching
- Admin panel for photo upload via Cloudinary
- Firestore real-time sync
- SEO via React Helmet

## Stack

React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Firebase, Cloudinary, AWS Amplify.

## Run locally

    npm install
    npm run dev
